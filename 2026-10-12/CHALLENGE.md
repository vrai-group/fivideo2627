## 4. Sconto sul prezzo

Dato:

```c
float prezzo = 120.0;
```

Se il prezzo è maggiore di `100`, applica uno sconto del `10%`.

Altrimenti, lascia il prezzo invariato.

Salva il risultato in:

```c
float prezzoFinale;
```

Infine stampa il prezzo finale.

## 5. Temperatura

Data:

```c
float temperatura = 28.5;
```

Usa l'operatore ternario per stampare:

* `Caldo` se la temperatura è maggiore o uguale a `25`
* `Fresco` altrimenti

Poi converti la temperatura in Fahrenheit usando la formula:

```c
fahrenheit = temperatura * 9.0 / 5.0 + 32;
```

e stampa il risultato.
